有些问题可以转化为两个前缀进行简单计算得到结果，如：一个数组子数组的和为K的个数，子数组的和，可以转化为两个前缀数组相减。
类似题目有：
[leetcode 209](https://leetcode.cn/problems/minimum-size-subarray-sum/)
[leetcode 560](https://leetcode.cn/problems/subarray-sum-equals-k/comments/)
[leetcode 862](https://leetcode.cn/problems/shortest-subarray-with-sum-at-least-k/)

以leetcode 560题为例
subsum = sum[i] - sum[j]
因此可以使用两次循环遍历获得，这么做时间复杂度为O(n2)。

可以在此基础上，进一步优化。在第一次循环中，我们已知sum[i]，subsum的目标值k，同时j<i。因此可以使用map，来检索是否存在sum[j]。时间复杂度降为O(n)。

```go
func subarraySum(nums []int, k int) int {
    length := len(nums)
    sum := make([]int, length)
    sum[0] = nums[0]
    for i := 1; i < length; i++ {
        sum[i] = sum[i-1] + nums[i]
    }
    pre := make(map[int]int, 0)
    ret := 0
    for i := 0; i < length; i++ {
        if sum[i] == k {
            ret++
        }
        one := sum[i] - k
        if value, ok := pre[one]; ok {
            ret += value
        }
        if _, ok := pre[sum[i]]; ok {
            pre[sum[i]] += 1
        } else {
            pre[sum[i]] = 1
        }
    }
    return ret
}
```

标准答案中的代码更加简洁，也节省了时间、空间,sum已经存储到map中不必再使用[]int,节省空间,同时将sum的计算与判断是否有子数组放到一个循环里，节省了时间
```go
func subarraySum(nums []int, k int) int {
    count, pre := 0, 0
    m := map[int]int{}
    m[0] = 1
    for i := 0; i < len(nums); i++ {
        pre += nums[i]
        if _, ok := m[pre - k]; ok {
            count += m[pre - k]
        }
        m[pre] += 1
    }
    return count
}
```

209题可以使用双指针滑动窗口，但560题则不行，因为560题中是整数，既有正数，也有负数，窗口的移动需要一步一迭代，窗口大小单调增长.
